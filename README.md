# Ziona Eyob — Personal Website

A single-page, dependency-free personal site. Open `index.html` in a browser, or serve the folder with any static host (GitHub Pages, Netlify, Vercel).

- `index.html` — content and structure
- `styles.css` — design tokens (light/dark), layout, animation
- `script.js` — theme toggle, rotating headline, count-up stats, scroll reveals

To publish on GitHub Pages: Settings → Pages → Deploy from branch → pick the branch and `/ (root)`.
